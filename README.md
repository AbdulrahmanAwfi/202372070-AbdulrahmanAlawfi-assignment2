## tasks description
In this assignment, i added dynamic navigation buttons that navigate to the sections (such as about).
Where it reads the button pressed ID and navigate the page to it.

I also added very simple data handling tool that memorizes weather the user previously prefered dark
or light them using the localstorage, it initializes the theme to light.

Also added a very simple smooth transition improvement, where pressing any pf the navigation buttons
the page scrolls to it smoothly and not immediatly.

it alerts the user and telling him to refresh the page.
